# Site — dNATY

Site do [dNATY](https://github.com/pedrovergueiro/dNaty), minha biblioteca de compressão de redes neurais. Desenvolvi pra apresentar o projeto de forma clara pra quem chega sem contexto — seja um pesquisador, um engenheiro ou alguém que só viu o link em algum lugar.

O maior aprendizado aqui foi entender que apresentar um projeto técnico pra um público amplo é tão difícil quanto construir o projeto em si. Escrever a página de código com exemplos claros me forçou a pensar em como explicar NAS e compressão de modelos sem pressupor que o leitor conhece os termos.

## Páginas
- `index.html` — apresentação do projeto
- `codigo.html` — exemplos de código prontos pra copiar
- `guia.html` — guia de início rápido
- `launch.html` — página de lançamento
