# Site do dNATY

O site que desenvolvi pra apresentar o [dNATY](https://github.com/pedrovergueiro/dNaty) — minha biblioteca de compressão de redes neurais — de forma clara pra quem chega sem saber nada sobre o projeto.

Foi meu primeiro projeto de frontend mais sério. Aprendi na prática que escrever HTML e CSS limpos é mais difícil do que parece, especialmente quando você quer que o site seja responsivo e fácil de navegar.

## Páginas
- `index.html` — Página inicial com apresentação do projeto
- `codigo.html` — Exemplos de código de uso
- `guia.html` — Guia de início rápido
- `launch.html` — Página de lançamento

## Stack
HTML · CSS · JavaScript
